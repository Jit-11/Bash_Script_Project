🧪 Capstone Homework: Build a Bash File & Log Management System
You are going to build a command-line tool called file_manager.sh.

The goal is to manage a directory of files, analyze them, search their contents, create reports, and perform actions based on user input.

Rules
Use Bash, not Python.

Don't look up solutions while doing the core tasks.

You can use man pages when you genuinely forget syntax.

Try to solve each level yourself before moving on.

Your script should be executable with:

chmod +x file_manager.sh
./file_manager.sh

Part 1 — Set up your laboratory
Create this structure:

bash-homework/
├── file_manager.sh
├── data/
│   ├── logs/
│   ├── documents/
│   ├── images/

Create at least 20–30 lines of mixed data across your files.

Part 4 — Searching Challenge
Now forget about your script for a moment.

Suppose you want to answer:

How many ERROR lines exist across all log files?: find . -type f -name '*.log' -exec grep -iH 'error' {} \; | wc -l

Which files contain WARNING?: find . -type f -name '*.log' -exec grep -il 'warn' {} \;

Show me every line containing Database.: find . -type f -name '*.log' -exec grep -i 'database' {} \;

Show me only the first few matching lines.: find . -type f -name '*.log' -exec grep -i 'error' {} \; | head -n2

Use the tools you learned rather than manually opening files.

You should be able to investigate your data from the terminal.

🔥 Rules for the Final Project
Try to make yourself obey these rules:

Rule 1 — No hardcoding results
Bad:

echo "Total files: 25"

Good:

count=$(...)
echo "Total files: $count"

Rule 2 — Validate user input
If the user enters:

99

don't let your program break.

Say:

Invalid option.
Please choose 1-11.

Rule 3 — Handle missing files
If the user enters:

abc.txt

and it doesn't exist:
Error: file does not exist.

Rule 4 — Use functions
Don't write one giant 300-line script.

Rule 5 — Use case
Your menu should naturally use a case statement.

Rule 6 — Use loops
Your menu should continue until the user chooses Exit.

Rule 7 — Use arrays
At least one indexed array and one associative array.

Rule 8 — Use command substitution
At least several places where you dynamically capture command output.

Rule 9 — Use cut and tr
Don't just practice them separately—use them in your project.

Rule 10 — Use man
When you forget something, your first instinct should be:

man command

rather than immediately searching Google.
